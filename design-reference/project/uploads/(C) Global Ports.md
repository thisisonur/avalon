# Global Ports

**Subtitle:** One system. Fifteen distinct personalities.

**Role:** Creative Director
**Year:** 2017

---

**Description**

Global Ports operates cruise terminals across Europe and Asia. Each port needed a distinct online presence that reflected its location and character, while sharing the same structural foundation underneath.

I led a small team as Creative Director, managing the client relationship and keeping brand consistency across every site. The approach was a common layout system paired with individual color palettes that carried the identity of each port. The system was flexible enough for local variation but consistent enough that nothing got lost across fifteen locations.
