# HASTE: A Headless Design System

**3 min read**

A flexible, reusable design system built to help teams start new client projects faster, without rebuilding the same components and patterns from scratch every time.

---

## My Role

Design System Designer and System Advocate
2023
**Duration:** 18 months

---

## The Situation

At Hide and Seek Digital, every new client project needed its own design system. But every time, we rebuilt the same basic components and design rules from scratch. We had buttons, forms, and layouts that we had already designed before. We just made them again and again.

This meant:
- Designers spent weeks on basics instead of solving real problems
- Engineers had to code the same components over and over

We needed something we could reuse across projects, like a foundation that every new project could build on top of.

---

## What I Did

I designed and built HASTE - a design system that works like a toolkit. It has over 200 components (buttons, forms, navigation, etc.) that designers and engineers could use right away for any new project.

The key idea: **Make it flexible but consistent.** The system is like a skeleton - it has no colors, fonts, or brand style built in. When a team starts a new client project, they add that client's brand tokens (colors, fonts, spacing rules, etc.) on top of HASTE. This way, every client gets a unique look that matches their brand, but the components underneath stay the same and work reliably.

I also:
- Wrote clear guides for designers on how to use components
- Worked with engineers to make sure components worked correctly
- Made sure all components met accessibility standards
- Ran training sessions to teach teams how to use the system
- Partnered with Storyblok to present the system in a webinar to 100+ people from other companies

---

## Results

With HASTE, new client projects moved much faster. Designers didn't waste time rebuilding basics. Instead, they focused on solving real problems for each client.

The system helped teams:
- Start new projects 20% faster
- Keep everything looking consistent
- Have confidence components work correctly
- Work together more smoothly between design and engineering

It's now used across multiple client projects, including the Australian Federal Police and Relate.

---

**Key takeaway:** Sometimes the biggest impact comes from building something that saves everyone time, not from a fancy new feature.
